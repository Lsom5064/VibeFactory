# 터치 기반 UI 수정과 도움말 복구

- 도움말 안의 **도움말 버튼 숨기기**는 생성 앱 전체에 적용되며 재실행·리비전 업데이트 후에도 유지된다. 숨긴 동안 자동 안내도 표시하지 않는다.
- VibeFactory의 **로그 보기** 화면에서 APK 영역 아래 **도움말 다시 표시**를 누르면 현재 설치된 해당 패키지를 열고 도움말 버튼을 복원한다. 새 빌드의 공통 런타임과 manifest가 필요하며, 복구 진입점이 없는 이전 APK에는 업데이트 안내를 표시한다.
- 도구 아이콘은 터치로 선택한다. 삭제는 여러 대상을 선택한 뒤 **선택한 N개 삭제**로 한 번에 주석을 적용한다. 다시 누르면 선택이 해제되고, 선택한 부모의 자손은 중복 선택하지 않는다. 일괄 적용은 한 번의 실행 취소로 복구된다.
- 이동 대상은 터치로 선택하고 목적지는 드래그로 지정한다. 파란 실선 원본은 고정하며, 원본 크기의 파란 점선 영역을 화살표 끝 중심에 예약한다. 겹치는 UI를 아래로 밀고 이어지는 요소의 충돌도 조정한다. 다른 열과 원본은 유지한다.
- 이동의 배치 변화는 편집 미리보기의 XML `translationY`와 View 위치에 반영한다. 원본 XML과 저장하는 수정 주석은 별도로 유지한다. 이동 취소·실행 취소·화면 재진입 시 주석을 기준으로 미리보기를 다시 계산한다.
- 늘어난 스크롤 높이 때문에 좌표가 달라지지 않도록 주석 XML에 `referenceCanvasWidthDp`, `referenceCanvasHeightDp`, `previewCanvasHeightDp`를 기록한다. 정규화 좌표는 원래 캔버스 기준이다. 서버는 이동 목적지의 dp 중심도 생성 프롬프트에 포함한다.
- 기능 변경은 도구 → 대상 → 설명으로 진행한다. 추가는 도구 → 위치 → 영역 → 스케치·설명 순서다. 영역은 새 위치를 눌러 옮기고, 모서리와 새 위치를 차례로 눌러 크기를 조절한다. 스케치 그리기는 펜 동작을 유지한다.
- 도구 선택 중에는 대상 선택이 우선이며, 일반 상태에서 기존 표시를 누르면 해당 표시의 수정·삭제 확인창을 연다. 이동으로 밀려난 표시를 선택해도 저장 좌표는 원본 기준을 유지한다.

## 검증 범위

서버 계약 테스트는 기존 프로젝트 manifest 복구, 원본 XML 보존, 초안·이미지 저장과 좌표계를 확인한다. 호스트 단위 테스트는 다중 선택·중복 제거·일괄 실행 취소 및 이동 충돌 전파를 확인한다. Android instrumentation에는 원본 고정·XML 미리보기 재렌더링, 도움말 숨김·복구와 실제 화면 터치 및 API 저장 흐름이 포함된다.

`UiTouchFlowInstrumentedTest`는 `touchTaskId` 인자가 있고, 호스트 패키지 접미사가 `.touchhelpverify`이며, API가 격리된 로컬 18090 포트일 때만 실행한다. 운영 호스트·DB의 참가자 데이터를 테스트에 사용하지 않는다.
